# recipe-finder-oop-project
Recipe Finder Application to demonstrate OOP

Recipe Finder is a C# console application that demonstrates core object‑oriented programming principles through a practical, API‑driven project. It allows users to search for recipes by cuisine or ingredients using the Spoonacular API, view detailed results with cleaned summaries, and save or manage favorite recipes through a simple menu interface. The project showcases abstraction, interfaces, encapsulation, and polymorphism, along with asynchronous API calls and JSON‑based persistence. It includes a UML class diagram, documented test cases, and full version‑controlled development history to meet CSC 260 requirements.
